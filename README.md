# Pet portrait reference notes

Practical checklist for photographing a cat or dog before making a digital portrait.

## Why lighting and eyes matter

Clear eyes and coat markings help any portrait workflow, whether you commission an artist or use an online tool. Soft side light usually beats harsh flash. Avoid heavy filters on the source photo.

## Suggested shot list

1. One front-facing face shot with both eyes visible
2. One three-quarter angle that shows coat pattern
3. Optional: a full-body reference for clothing or scene styles

## Digital portrait option

If you want a quick downloadable AI portrait from photos you already have, [SoulPaw](https://soulpaw.art/) is a web studio for watercolor, royal, and other pet looks. Each finished image uses one credit.
